# Ntags — NFC review tags

Коммерческий сайт бренда Ntags: Standard и Custom, публичная ценовая сетка Standard, калькулятор тиража, корзина и отправка заявки в Telegram.

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm start
```

Откройте http://localhost:4173. Проверка синтаксиса: `npm run check`.

## Публикация

Сайт публикуется на GitHub Pages через GitHub Actions из ветки `main`. При каждом push в `main` workflow собирает статический сайт и запускает публикацию. Исходники остаются в корне репозитория; сборка Pages создаётся в `dist/` и не коммитится.

URL проекта: https://davidmitroshin-ui.github.io/Ntags/

В репозитории Settings → Pages → Build and deployment → Source должно быть выбрано **GitHub Actions**.

## Резервные копии

Git хранит полную историю коммитов. Перед крупными обновлениями создаётся ветка `backup/<описание>-YYYY-MM-DD`, чтобы можно было вернуться к последней стабильной версии. Релизы следует фиксировать отдельными Git-тегами. Не удаляйте backup-ветки, пока новая версия не проверена.

## Каталог и цены

Standard: 1 шт. — 1 190 ₽; 2–4 — 1 090 ₽/шт.; 5–9 — 990 ₽/шт.; 10–19 — 890 ₽/шт.; 20–49 — 790 ₽/шт.; 50+ — от 690 ₽/шт. Доставка включена. Custom — индивидуальный расчёт, доставка включается в согласованную стоимость.

## Важные ограничения текущей версии

- Корзина хранится в браузере и отправляет заявку в Telegram.
- Онлайн-оплата, серверное хранение заказов и административная панель пока не подключены.
- Прямая ссылка ведёт к форме написания отзыва, если это поддерживается выбранной площадкой и ссылкой заказчика.
- Не храните API-ключи, пароли, персональные данные покупателей или производственные секреты в публичном репозитории.
